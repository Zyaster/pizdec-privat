# ⚡ ROM Flasher & Root Simulator (4PDA Edition)

> **Почувствуй себя настоящим гуру мобильного моддинга, прошивок и раскирпичивания!**
> Симулятор прошивки смартфонов, кастомных рекавери, разгона процессора и получения Root-прав со сленгом 4PDA и реальными интерактивными операционными системами.

---

## 🆕 Что нового в этой сборке

- Полностью переработан интерфейс: теперь **у каждой ОС свой лаунчер**, а не общий «стеклянный дашборд».
- Свои обои, статус-бар, виджеты, док-панель, форма иконок и режим навигации для каждой системы.
- **Настройки переписаны с нуля** — отдельная вёрстка и свои разделы под каждую ОС, с поиском и подстраницами.
- Добавлены **Evolution X** и **Kali NetHunter** — всего шесть систем.
- Сборка APK без Android Studio теперь работает и в путях с пробелами.

---

## 🎮 Особенности игры

- 📱 **Реалистичный эмулятор смартфона (Poco X3 Pro / vayu)**:
  - Физические кнопки громкости и питания на корпусе с поддержкой комбо-нажатий.
  - Режим **Fastboot** с выводом аппаратных статусов (`DEVICE STATE - locked/unlocked`).
  - **TeamWin Recovery Project (TWRP)** с сенсорным управлением, выбором ZIP-архивов и легендарным **Swipe to Flash**.
  - Защита от кривой установки: если прошить кастом без `Format Data`, телефон падает в **Qualcomm CrashDump Mode** (бутлуп)!
  - Сервисный инструмент **Mi Flash Tool** для отката на официальную прошивку и раскирпичивания.

- 💻 **Рабочая станция мододела (ПК)**:
  - Консоль **Fastboot & ADB Toolkit** (`fastboot devices`, `fastboot oem unlock`, `fastboot flash recovery`, `adb push` и др.).
  - Ветка форума **4PDA.to** с темами кураторов, инструкциями и центром загрузки файлов.
  - Управление кабелем USB (подключение/отключение интерфейса).

## 🤖 Шесть систем — шесть интерфейсов

| Система | Оболочка | Фирменные детали |
|---|---|---|
| **Xiaomi HyperOS** | Голубые обои, тонкие часы | Чипы шагов и погоды, Mi-аккаунт, белые карточки настроек, скруглённые иконки |
| **PixelOS 14** | Material You | At a Glance, двухстрочные часы, круглая строка поиска Google, круглые иконки |
| **LineageOS 21** | AOSP / Trebuchet | Trust-виджет, зелёно-бирюзовый акцент, AOSP-список настроек, Privacy Guard |
| **crDroid 10.5** | Gaming Edition | Красный HUD (FPS / GHz / GPU / temp), терминальные подписи, crDroid Settings |
| **Evolution X 8.5** | The Evolver | Градиент Nebula, пилюли, кастомизация статус-бара и часов |

### ⚙️ Настройки

- Поиск по настройкам, сгруппированные разделы, иконки, тумблеры и плитки выбора.
- Подстраницы: **О телефоне**, **Экран**, **Батарея**, **Сеть**, **Безопасность**, **Разработчик**, **Система**, **Пасхалка**.

## 🛠️ Встроенные приложения внутри виртуальной ОС

- **Настройки**: информация об устройстве, статус загрузчика, частота экрана, DPI, тёмная тема, сеть, батарея, безопасность и режим разработчика.
- **Termux**: настоящий терминал с поддержкой команд `uname -a`, `id`, `getprop`, `reboot` и запросом прав суперпользователя `su`.
- **Magisk Manager v27.0**: управление root-доступом, переключатель **Zygisk**, запрос Superuser с таймером и менеджер модулей.
- **KernelSU Manager**: root на уровне ядра и скрытие от банковских приложений.
- **СберБанк Онлайн**: проверка **SafetyNet / Play Integrity API**. Если загрузчик разблокирован или есть Root без модуля `Play Integrity Fix` — банк блокирует вход!
- **AnTuTu Benchmark v10**: тестирование CPU/GPU/RAM с подсчётом баллов (от 560k на стоке до 1,140k+ на разогнанном crDroid).
- **FKM Разгон**: регулировка частот CPU/GPU, governor, zram и теплового профиля.
- **PUBG Mobile 120 FPS Arena**, **4PDA Форум**, **MT Manager** и другие приложения.

## 📲 Установка игры

Готовый подписанный установочный файл лежит в корне репозитория и папке `release/`:
- **`RomFlasherSimulator.apk`**

### Установка через ADB:
```bash
adb install RomFlasherSimulator.apk
```

Либо скопируйте APK на телефон и откройте его вручную (нужно разрешить установку из неизвестных источников).

---

## 🛠️ Сборка из исходников

Для сборки APK не нужен Android Studio — достаточно JDK 21 и Android SDK (build-tools 34.0.0, platform android-34):

```bash
./build_apk.sh
```

Скрипт сам компилирует ресурсы через `aapt2`, собирает Java, конвертирует в DEX через `d8`, выравнивает `zipalign` и подписывает `apksigner`.

Результат:
- `release/RomFlasherSimulator.apk`
- `RomFlasherSimulator.apk` (копия в корне)
