# ⚡ AndroFlash: ROM Flasher & Root Simulator (4PDA Edition)

> **Почувствуй себя настоящим гуру мобильного моддинга, прошивок и раскирпичивания!**
> Симулятор прошивки смартфонов, кастомных рекавери, разгона процессора и получения Root-прав со сленгом 4PDA и реальными интерактивными операционными системами.

---

## 🎮 Особенности игры

- 📱 **Реалистичный эмулятор смартфона (Poco X3 Pro / vayu)**:
  - Физические кнопки громкости и питания на корпусе с поддержкой комбо-нажатий.
  - Режим **Fastboot** с выводом аппаратных статусов (`DEVICE STATE - locked/unlocked`).
  - **TeamWin Recovery Project (TWRP)** с сенсорным управлением, выбором ZIP-архивов и легендарным **Swipe to Flash**.
  - Защита от кривой установки: если прошить кастом без `Format Data`, телефон падает в **Qualcomm CrashDump Mode** (бутлуп)!
  - Сервисный инструмент **Mi Flash Tool** для отката на официальную прошивку и раскирпичивания.

- 💻 **Рабочая станция мододела (ПК)**:
  - Консоль **Fastboot & ADB Toolkit** (`fastboot devices`, `fastboot oem unlock`, `fastboot flash recovery`, `adb push` и др.).
  - Ветка форума **4PDA.to** с темами кураторов, инструкциями и центром загрузки файлов.
  - Управление кабелем USB (подключение/отключение интерфейса).

- 🚀 **Интерактивные операционные системы**:
  - **Stock HyperOS / MIUI 14**: Официальная прошивка с фирменным стилем и базовой производительностью.
  - **PixelOS Android 14**: Чистый Pixel Experience, Monet UI и поддержка Google сервисов.
  - **LineageOS 21 (AOSP)**: Максимальная автономность, удаление телеметрии и легковесность.
  - **crDroid 10.5 Gaming Edition**: Игровой твик, разгон дисплея до 120Hz и оверклок CPU.

- 🛠️ **Встроенные приложения внутри виртуальной ОС**:
  - **Настройки**: Информация об устройстве, статусе загрузчика и Пасхалка с активацией режима разработчика (7 тапов по номеру сборки).
  - **Termux**: Настоящий терминал с поддержкой команд `uname -a`, `id`, `getprop`, `reboot` и запросом прав суперпользователя `su`.
  - **Magisk Manager v27.0**: Управление root-доступом, переключатель **Zygisk**, запрос Superuser с таймером и менеджер модулей.
  - **СберБанк Онлайн**: Реальная проверка **SafetyNet / Play Integrity API**. Если загрузчик разблокирован или есть Root без модуля `Play Integrity Fix` — банк блокирует вход!
  - **AnTuTu Benchmark v10**: Тестирование CPU/GPU/RAM с подсчетом реального балла производительности (от 560k на стоке до 1,140k+ очков на разогнанном crDroid!).

- 🏆 **Система квестов и прокачки репутации на 4PDA**:
  - От новичка с заблокированным загрузчиком до мастера оверклокинга.

## 📲 Установка игры

Готовый подписанный установочный файл лежит в корне репозитория и папке `release/`:
- **`RomFlasherSimulator.apk`**

### Установка через ADB:
```bash
adb install RomFlasherSimulator.apk
```

---

## 🛠️ Сборка из исходников

Для самостоятельной сборки APK без тяжелого Android Studio используется легковесный скрипт:
```bash
./build_apk.sh
```
