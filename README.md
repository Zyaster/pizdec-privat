# ROM Flasher & Root Simulator

Симулятор прошивки Android-смартфона. Виртуальное устройство — Poco X3 Pro (vayu):
загрузчик, fastboot, recovery, кастомные прошивки, root, разгон и «рабочая станция
мододела» с форумом 4PDA.

Приложение собрано как WebView-оболочка: интерфейс и логика лежат в
`app/src/main/assets` (`index.html`, `style.css`, `app.js`), нативная часть — только
запуск WebView и вибрация.

## Что можно делать

- Включать и выключать виртуальный телефон, зажимать комбинации кнопок.
- Уходить в fastboot, разблокировать загрузчик, прошивать recovery.
- Ставить TWRP или OrangeFox, делать Format Data, прошивать ZIP.
- Ловить бутлуп при неправильной последовательности и поднимать устройство через
  Mi Flash Tool.
- Ставить PixelOS, LineageOS, crDroid, Evolution X или Kali NetHunter.
- Получать root через KernelSU или Magisk, ставить модули Zygisk.
- Разгонять CPU/GPU, гонять AnTuTu и PUBG-арену, проверять Play Integrity в банке.
- Работать в терминале (Termux), редактировать `build.prop` в MT Manager.

## Шесть систем

Переключение прошивки меняет не только обои: у каждой системы свой лаунчер, сетка,
форма иконок, док, виджеты, статус-бар, режим навигации и отдельно свёрстанные
настройки.

| Система | Версия | Что характерно |
|---|---|---|
| Xiaomi HyperOS | 1.0.4 Global | крупные тонкие часы, карточки настроек, синий акцент `#3482FF`, 4 колонки |
| PixelOS | 14 QPR3 | Material You, At a Glance, поиск Google, 5 колонок |
| LineageOS | 21 | Trebuchet, Trust, AOSP-список настроек, бирюзовый акцент |
| crDroid | 10.5 | AOSP-база, красный акцент, строка системных показателей |
| Evolution X | 8.5 | The Evolver, фиолетовый акцент, плоские списки |
| Kali NetHunter | 2024.2 | терминал на рабочем столе, chroot, моноширинный интерфейс |

Версия 1.9 — это переработка оформления: убраны градиентные «промо»-фоны, стекло и
неон, обои и типографика приведены к тому, как выглядят стоковые оболочки, настройки
каждой системы переверстаны под её реальный вид.

## Встроенные приложения

- **Настройки** — свой интерфейс под каждую ОС, поиск, подстраницы, пасхалка по
  7 тапам на номере сборки.
- **Termux** — `uname`, `id`, `getprop`, `su`, `neofetch` и другие команды.
- **Magisk** — Zygisk, модули, запрос суперпользователя.
- **KernelSU** — root на уровне ядра, скрытие от банковских приложений.
- **СберБанк** — проверка Play Integrity; с разблокированным загрузчиком и root без
  Play Integrity Fix вход блокируется.
- **AnTuTu** — тест CPU/GPU/RAM, от ~560k на стоке до 1,1M+ на разогнанном ядре.
- **FKM** — частоты, governor, zram, тепловой профиль.
- **PUBG Arena**, **4PDA**, **MT Manager**.

## Установка

Готовый APK лежит в корне репозитория и в `release/`:

```
RomFlasherSimulator.apk
```

```bash
adb install -r RomFlasherSimulator.apk
```

Или скопировать на телефон и открыть вручную (нужно разрешить установку из
неизвестных источников).

> Начиная с 1.9 APK подписан новым ключом. Если старая версия уже установлена,
> её нужно удалить перед установкой.

## Сборка

Android Studio не нужен: достаточно JDK и Android SDK (build-tools 34.0.0,
platform android-34).

```bash
./build_apk.sh
```

Скрипт компилирует ресурсы через `aapt2`, собирает Java, конвертирует в DEX через
`d8`, выравнивает `zipalign` и подписывает `apksigner`. Результат —
`release/RomFlasherSimulator.apk` и копия в корне.
