**RomFlasherSimulator.apk** — версия 1.9.

### Что изменилось

- Переработано оформление всех шести систем: убраны градиентные фоны, размытие и
  неоновые свечения, которые не встречаются в стоковых оболочках.
- Обои заменены на мягкие градиенты с зерном, ближе к реальным стоковым валлпейперам.
- Типографика приведена к Roboto/Noto Sans, часы и заголовки — к весам и размерам
  оригинальных лаунчеров.
- Иконки: единая squircle-форма с разным радиусом под каждую ОС, плоские цвета дока
  вместо градиентов, у Pixel, LineageOS, crDroid и Evolution X — сетка в 5 колонок.
- Док больше не «плавающая капсула»: у всех систем прозрачный фон, как в стоке.
- Статус-бар: вместо текстовых плашек `KernelSU` / `# SU` — обычные значки, частота
  обновления показывается только там, где это есть в системе (crDroid, Evolution X).
- Виджеты переписаны: HyperOS — часы, дата, погода и шаги; Pixel — At a Glance и
  двухстрочные часы; LineageOS — часы и Trust; crDroid — компактная строка
  показателей; Evolution X — часы и подпись сборки; Kali — терминал.
- Настройки: у HyperOS карточки с цветными иконками, у Pixel — круглые иконки
  Material You, у LineageOS, crDroid и Evolution X — плоский AOSP-список с
  разделителями и акцентными заголовками, у Kali — терминал.
- Из интерфейса убраны эмодзи: папки в MT Manager, заголовки приложений, диалоги,
  пасхалка и квесты используют текстовые подписи и векторные иконки.
- README и релизные заметки переписаны без рекламных формулировок.

### Установка

```bash
adb install -r RomFlasherSimulator.apk
```

APK подписан новым ключом. Если установлена предыдущая версия, сначала удалите её:

```bash
adb uninstall com.romflasher.app
adb install RomFlasherSimulator.apk
```
